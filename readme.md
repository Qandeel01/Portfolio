# Qandeel Ahmad Portfolio — Redesign

A responsive, animated portfolio built with plain HTML, CSS, and JavaScript.

No npm installation or build step is required.

## Files

- `index.html` — Page content, project entries, SEO metadata, and contact form.
- `style.css` — Visual system, responsive layout, animations, and project previews.
- `script.js` — Mobile navigation, scroll reveals, interactive hero, technology tabs, and active navigation.
- `favicon.svg` — Custom website icon.

## Run locally

Open `index.html` in a browser.

Alternatively, run this command from the project directory:

python -m http.server 8000

Then visit:

http://localhost:8000

## Before publishing

1. Keep this folder at the root of your GitHub Pages repository.
2. Keep your existing project folders beside `index.html`.
3. Test the Formspree contact form after publishing.
4. Replace the LinkedIn link with your actual profile URL.
5. Update project descriptions and technologies as needed.

## Deploy to GitHub Pages

Commit the updated files to the branch and folder configured in your repository's Settings → Pages.

GitHub Pages can publish these static files directly. A React or Vite build is not required.
